# Bunny Planner

Organizador de rotina interativo desenvolvido com JavaScript, PHP e MySQL.

## Sobre o projeto

O Bunny Planner é uma aplicação web criada para organizar tarefas e compromissos de forma simples e visual.

O projeto foi desenvolvido com foco em uma interface limpa e minimalista, explorando conceitos de UX/UI e integração entre front-end, back-end e banco de dados.

## Funcionalidades

- Cadastro e login de usuários
- Criação e gerenciamento de tarefas
- Calendário interativo
- Exibição de informações em modais
- Interface responsiva

## Tecnologias

- HTML5
- CSS3
- JavaScript
- PHP
